# Skill 04 · 实现与自校验

**何时用**：任务已拆解，开始写代码。

## 步骤

1. 每轮只做一个任务，做完就验，不要攒一堆。
2. 按 AGENTS.md 的"最小改动 / 外科手术式改动"执行。
3. 改完自己先跑校验，不要等人发现：
   - 语法检查（node --check / python -m py_compile 等）
   - 配置数量 / 结构检查
   - 残留关键词检查（占位、幕后说明）
4. 涉及会变的内容，确认已配置化；涉及数据结构，确认版本与迁移已处理。
5. 验证通过再 commit。

## 完成定义

任务勾选 + 验证命令有输出且通过 + 无遗留报错。不通过就不标完成。

## 反例

- 改完直接说"做好了"，没跑任何校验
- 一个 commit 塞五个任务，出问题无法定位
- 顺手重构无关代码，把 diff 搞大
