# Skill 05 · 交接与复盘

**何时用**：阶段完成、需要交给另一个 Agent、或项目告一段落。

## 交接步骤

1. 更新 `handoff/HANDOFF.md`：做了什么 / 验证结果 / 下一步（按 PROTOCOL.md）。
2. commit，一个阶段一个 commit。
3. 通知人或触发下一个 Agent。

## 复盘步骤

1. 抽出本次的**可复用经验**，写进对应 skill 或 AGENTS.md——不是写流水账。
2. 踩过的坑写成"反例"条目，附正确做法。
3. 如果规范本身有改动，在 README 状态区打勾，并记录版本号。

## 规范持续迭代

规范仓库和代码项目一样，需要版本化迭代：

```
v1.0 骨架 + 五步框架 + 交接协议
v1.1 补项目现场手册 + 上下文与 Token 效率规范（skills/09）
v1.2 首个试跑反馈 + 沉淀踩坑模式库
v1.3 部署与运维规范（skills/10）
```

每次项目收口后问一句：这次有没有值得加进规范的？有就提交，规范才会"持续优化"而不是一次性文档。
